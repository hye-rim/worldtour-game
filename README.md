# 세계 일주 보드게임 🌏

주사위를 굴려 도시를 사고 건물을 지어 통행료를 받는 보드게임입니다. 컴퓨터 세 명(민수·지아·도윤)과 겨루는 혼자 하기이고, 서버 없이 `index.html` 만 열면 돌아갑니다. 돈은 게임용이며 단위는 만 원입니다.

> 한국의 유명 보드게임과 같은 종류의 게임이지만, 상표와 판 그림을 쓰지 않으려고 이름·판·도시 배치·값은 직접 정했습니다.

- 조작: 아래 큰 버튼(주사위 굴리기 · 구매/건설)과 보조 버튼(안 사요/안 지어요 · 무인도 탈출). 키보드는 `Space/Enter`, `N`(건너뛰기), `P`, `M`. 우주여행은 판에서 도착할 칸을 직접 누릅니다.
- 규칙과 컴퓨터는 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙
- 32칸: 도시 18곳(색 묶음 6개 × 3곳), 관광지 3곳(제주도·콩코드·크루즈), 황금열쇠 6칸, 모서리 4칸(출발 · 무인도 · 사회복지기금 수령 · 우주여행), 사회복지기금 납부 1칸.
- 시작은 200. 출발 칸을 지나거나 밟으면 월급 15.
- 주인 없는 도시에 서면 살 수 있고, 내 도시에 다시 서면 **별장 1 → 별장 2 → 빌딩 → 호텔** 순서로 지을 수 있습니다. 건물이 높을수록 통행료가 크게 오릅니다. 같은 색 세 곳을 모두 가지면 땅 통행료가 두 배입니다. 관광지는 건물 대신 가진 관광지 수에 따라 통행료가 커집니다.
- 남의 도시에 서면 통행료를 냅니다. 돈이 모자라면 건물(높은 것부터)과 땅(싼 것부터)을 반값에 **자동 매각**하고, 그래도 모자라면 파산합니다(재산은 은행으로, 남은 돈은 받을 사람에게).
- **더블**이 나오면 한 번 더 굴리고, 세 번 연속이면 무인도로 갑니다.
- **무인도**: 더블이 나오면 탈출, 20을 내고 탈출, 탈출권(황금열쇠)으로 탈출, 세 번 실패하면 20을 내고 나옵니다.
- **사회복지기금**: 납부 칸의 15와 황금열쇠 벌금·수리비가 쌓이고, 수령 칸에 서면 전부 가져갑니다.
- **우주여행**: 이 칸에 서면 다음 차례에 주사위 대신 원하는 칸으로 날아갑니다(출발을 지나면 월급).
- **황금열쇠**: 보너스 · 복권 · 벌금 · 생일(모두에게 5씩) · 출발지로 · 무인도로 · 탈출권 · 앞/뒤 3칸 · 우주여행 · 건물 수리비. 한 벌을 섞어 모두 뽑으면 다시 섞습니다.
- **30바퀴**가 끝나면 자산(현금 + 땅값 + 지은 건물값)이 가장 많은 사람이 이기고, 그 전에 나만 남아도 이깁니다. 시작하는 사람은 무작위입니다.
- **난이도**(시작 화면에서 선택): 「쉬움」은 컴퓨터가 땅을 덜 사고(45% 건너뜀), 건물을 덜 짓고(60% 건너뜀), 돈을 많이 쥐고 있습니다. 쉬움에서는 최고 기록이 저장되지 않습니다. 시뮬레이션에서 보통 컴퓨터와 같은 실력의 플레이어가 쉬움 컴퓨터 셋을 상대하면 70% 이긴다(120게임).

## 참고한 것과 제가 정한 값
- 공개 자료([나무위키 게임 방법](https://namu.wiki/w/%EB%B6%80%EB%A3%A8%EB%A7%88%EB%B6%88/%EA%B2%8C%EC%9E%84%20%EB%B0%A9%EB%B2%95) 등)에서 확인한 틀: 시작 200만, 대지에서 별장·빌딩·호텔 순으로 짓는 구조, 무인도(더블이나 탈출권으로 탈출), 사회복지기금, 우주여행, 황금열쇠, 출발 칸 월급.
- 판본마다 달라서 **제가 정한 값**: 칸 순서, 도시 이름·가격, 통행료 배수, 건설비, 월급 15, 관광지 값과 통행료, 황금열쇠 카드 목록, 30바퀴 제한, 반값 자동 매각, 컴퓨터의 판단 기준.
- 넣지 않은 것: 남의 땅을 비싸게 사 오는 「인수」, 랜드마크, 플레이어끼리의 거래, 더블 위치·사이드 규칙의 판본별 차이.
- 그림과 소리는 직접 그린/합성한 것입니다.
